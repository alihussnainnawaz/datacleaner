Change Case

Apply UPPER, lower, Title, or camelCase to text columns. Pick one style for everything, or a different style per column.

Regex Clean

Select a column — similar values are grouped into clusters (e.g. "bdin", "badin", "BADin" → "Badin"). Edit the target name, remove a value that was grouped wrongly, or drag a value out of the wrong cluster, before applying anything to the dataset.

Trim Whitespace

Remove leading and trailing spaces from cell values. Apply to all columns or pick specific ones.

Not Null Check

Flag every cell that's missing or blank, for any column you choose — independent of the Unique / Not Null check used for primary-key columns (UUID/CNIC), which also checks duplicates. This is a plain "must have a value" check only. Flagged cells are marked for review, not auto-filled — there's no safe value to invent for a missing one.

Standardize Date Format

Select one or more date columns and choose the output format. The tool auto-detects columns whose names contain "date", "dt", "dob", "doj", "day", or "time".
